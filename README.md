# Number Guessing Game

A simple and interactive web-based Number Guessing Game built using HTML, CSS, and JavaScript.

## Features

- 🎲 Generates a random secret number between 1 and 100
- 🔢 Allows the user to enter guesses
- 📈 Provides hints when the guess is too high or too low
- 🔢 Tracks the number of attempts
- ⏳ Displays the remaining attempts
- 📝 Shows previous guesses
- ⚠️ Validates invalid and out-of-range inputs
- 🚫 Prevents duplicate guesses
- 🎉 Displays a success message when the correct number is guessed
- 🔄 Allows the user to start a new game
- 📱 Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Play

1. Enter a number between 1 and 100.
2. Click the **Guess** button.
3. Use the hint to determine whether your next guess should be higher or lower.
4. You have a maximum of 10 attempts.
5. Guess the secret number before your attempts run out.
6. Click **New Game** to start another round.
